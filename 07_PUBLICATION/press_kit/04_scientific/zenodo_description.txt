Lingua Executabilis Universalis (L.E.U.) is a novel, executable, and cryptographically traceable formal language. It bridges human cognition and machine verification through 20 universal semantic primitives (L0-L4), integrating deterministic SVG visual rendering, Web Audio API sonification, and cryptographic provenance (SHA-256 + OpenTimestamps).

The archive includes:
- A Python compiler and a WebAssembly (WASM) runtime.
- An interactive, AI-assisted node-based playground (React Flow).
- The Agentic Glyph, a self-sealing, sonorous SVG artifact.
- The TELA (Trusted Edge Logic Agents) protocol for verifying AI actions.
- An identity registry for cryptographic agent verification.
- A comprehensive whitepaper and the Multimodal Coherence Formula (FCM-20).
