# 🛡️ L.E.U. Quest Board

Welcome, Explorer. The L.E.U. Universe is infinite, but it is not yet complete. Your mission, should you choose to accept it, is to help us build the ultimate verifiable digital universe. 

## 🏆 The Genesis Quests

### Quest 1: The Awakening of OBSERVE (Legendary)
- **Objective**: Add the 21st primitive (`OBSERVE`) to the lexicon, create its SVG glyph, and its sonification.
- **Reward**: `OBSERVER` badge + 1000 XP.
- **Clue**: The 21st primitive is the one that watches all others.

### Quest 2: The Living PNG (Mythic)
- **Objective**: Create a PNG file that contains its own executable JavaScript code (Polyglot). When opened in a browser, the PNG must display its own SHA-256 hash.
- **Reward**: `POLYGLOT_MASTER` badge + 2000 XP.

### Quest 3: The Infinite Universe (Epic)
- **Objective**: Build a Three.js scene where the 20 primitives rotate in an infinite 3D space, reacting to mouse movements.
- **Reward**: `ARCHITECT` badge + 1500 XP.

### Quest 4: The TELA Protocol (Rare)
- **Objective**: Write a Python script that verifies an L.E.U. expression signed by an AI agent before executing a mock transaction.
- **Reward**: `TRUST_MASTER` badge + 800 XP.
